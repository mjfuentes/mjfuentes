## Projects

- **[cc+](https://github.com/kerplunkstudio/ccplus)**: open source orchestration and observability platform for AI coding agents. Runs parallel Claude Code sessions in isolated git worktrees under a supervisor that assigns work, watches it and retries.
- **[AMIGA](https://github.com/mjfuentes/amiga)**: the Python predecessor of cc+. 16 agents, model routing by cost, worktree isolation, an agent that rewrites its own prompts from its error log. Archived March 2026.
- **[SoundGround](https://github.com/mjfuentes/soundground)**: a living atlas of underground music scenes. Crawls the SoundCloud follow and repost graph, clusters artists into real communities and names each scene from the vocabulary its members use. Next.js, TypeScript, SQLite.
- **[ChessBud](https://github.com/mjfuentes/ChessBud)**: local opening trainer built from your own chess.com games. Works out which openings you actually reach and where you leak, then drills your real repertoire on Stockfish. Python.
- **[Summit](https://github.com/mjfuentes/summit)**: first attempt at an agent that extends its own code, merges only when CI is green. Archived June 2025, the ideas carried into AMIGA and cc+.
- **[YetAnotherCodingBot](https://github.com/mjfuentes/yetanothercodingbot)**: Telegram front end for Claude. Quick questions go to the API, coding tasks run in Claude Code in the background. Archived October 2025.
